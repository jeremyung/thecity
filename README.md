# The City

The City is an early browser simulation of a small Tokyo-inspired neighborhood. It runs a deterministic Rust simulation in WebAssembly and renders the same world with Three.js. You can leave it running, watch its streets change, explore by camera, and return to a locally saved city.

## Run it locally

Install Node.js 22 or newer, npm, and Rust. Before the first WASM build, install its target and matching bindings tool:

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version 0.2.108 --locked
```

Then from the project directory run:

```sh
npm ci
npm run wasm
npm run dev
```

Open the local address printed by Vite. Run `npm run wasm` again after changing the Rust engine. The build scripts use `.tools/cargo` and `.tools/rustup` when a local `.tools/cargo/bin` exists; otherwise they use the Rust tools on `PATH`.

## Checks

```sh
npm run setup:fixtures   # once; downloads pinned regression saves (Python 3.9+)
npm run test:engine -- --release
npm run wasm
npm test
npm run build
```

`npm test` includes compiled WASM integration tests and the pinned regression saves, so build WASM first. Fixture downloads are verified against a committed hash manifest. Offline setup: `npm run setup:fixtures -- --archive /path/to/test-fixtures.tar.gz`.

## Graphics, sound and saves

The renderer uses WebGPU where available, with a WebGL2 fallback (`?webgl=1` forces it). The simulation runs locally in a worker and needs no account. Saves use browser storage on the current device and can be exported and imported as JSON. Save compatibility across versions is not promised; a save from the current version must validate and resume.

The city and its sound are generated by the app: ambience and the score come from the Web Audio API, and buildings, streets, water and weather are rendered from geometry and code. [assets-manifest.json](assets-manifest.json) records the procedural sources.

Image generation is an offline asset-production option only. The browser never receives provider credentials; `scripts/generate-texture-pilot.mjs` reads `OPENROUTER_API_KEY` from the ignored `.env.local` (never use a `VITE_` prefix).
